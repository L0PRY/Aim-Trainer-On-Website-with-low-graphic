# AIMAREA
## Core Gameplay Mechanics
### Training Modes: 
The game features 14 distinct training scenarios categorized by skill type. These include standard modes like Gridshot and Sixshot for precision, Tracking and Strafetrack for smooth mouse movement, and Spidershot and Reflex for flicking and reaction times.

## Weapon System: 
The code defines specific weapon profiles inspired by tactical shooters. Guns like the Vandal, AK-47, AWP, and Sheriff are programmed with individual stats for fire rate (RPM), magazine size, damage, and recoil patterns (pitch and yaw).

## Scoring and Metrics: 
After a round finishes, the game calculates and displays performance metrics, including accuracy percentage, targets destroyed per second, average time-to-kill, and an overall letter grade.

##Customization and Settings
### Crosshair Editor:
There is a comprehensive crosshair configuration tool built in. It allows users to adjust inner and outer lines, center dots, thickness, gaps, opacities, and colors. It also includes an import/export function for crosshair codes and standard presets.

## Visual Adjustments: 
Users can change the color of the targets, the arena walls, and the floor. There are also toggles for hit particles and the visible weapon model.

## Input and Display:
The settings menu includes standard FPS adjustments like mouse sensitivity, DPI scaling, ADS multipliers, and Field of View (FOV) sliders. It also supports custom aspect ratios (like 4:3 stretched) and frame rate limiters.

## Additional Features
### Built-in Music Player: 
The code includes a fully functional local music player. Users can drag and drop their own audio files (MP3, WAV, etc.) into the browser to play in the background while they train, complete with volume and playback controls.

## Audio Synthesis:
Rather than relying entirely on external sound files, the game generates its hit, miss, and gunshot sound effects dynamically using oscillators through the Web Audio API.
